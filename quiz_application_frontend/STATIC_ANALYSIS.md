# Static analysis

This repository currently contains no application source files, so there is nothing substantive to lint/typecheck yet.

However, lightweight static analysis scaffolding is provided so future code additions can be checked immediately.

## Prerequisites
- Node.js + npm

## Install
```bash
npm install
```

## Lint
```bash
npm run lint
```

## Format check
```bash
npm run format:check
```

## Auto-format
```bash
npm run format
```
